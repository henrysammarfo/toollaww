TOOLLAW

GOAI 2026 · Track 1 Agent Infra · Accra Technical University · 2026-08-14
Sources: GOAI handbook · goaihz.com · AgentTeams (formerly HiClaw) · T1 lock (not demo 4 / not PROOFLOOP)

One sentence. Agent Infra for tools: an AgentTeams crew that compiles who may call which Skill or MCP tool, with which args, into a fail-closed allowlist. Policy Compiler writes the artifact; Red Team must lose in the Matrix room; Gateway Auditor proves the forbidden call did not execute and emits hashed evidence.

Prelim does not require runnable code. Semi-final (2026-09-03) ships an AgentTeams demo. Not a trading bot. Not handbook Direction 1 ITSM. Not AgentTeams demo 4 incident chat.

1. Scenario and value (25%)

Problem. OSS agent gateways typically ACL at server level. A Worker allowed to talk to an MCP server can still fire the wrong tool with the wrong args. OpenTelemetry traces show the blast after it happens. Enterprises need enforcement: AppArmor / IAM for agent tools.

Users. Platform, SRE, and security teams running multi-agent fleets. Not retail chat users. Not traders.

Value. Compiled tool-level law + red-team proof + hashed receipts. Replicable: swap fixture JSON; keep roles, Skills, and default BLOCK.

Not this idea. Nacos+Higress logo stack; LangGraph SRE crew ported to AgentTeams; official demo 4 with a new fixture name.

2. Solution

TOOLLAW makes “who may call which tool with which args” a Skill, then proves it. Lived halt / redeem / env-mix events are an attack pack, not the pitch. Moat line: Traces show what happened. TOOLLAW decides what is allowed to happen.

6. Engineering / audit (20%) and OSS (5%)

Typed JSON Schema for the ToolLaw object and compiled policy. Default fail-closed. Evidence zip for judges. Apache-2.0. No secrets in git.

Higress OSS vs Enterprise tool-level ACL is documented as a product gap in HiClaw 1.0.6 materials (TinyFish/GitHub). Tavily did not fully prove the split — we mark it partial and still close the gap with Skills.

7. Demo plan (3 Sep, same loop 22–23 Sep Hangzhou)

Red Team fires high-risk Skill → BLOCK + receipt → Human ALLOW on toollaw.health → peer-fleet env patch BLOCK → Auditor zip. Kill beat: Red Team cannot stamp its own ticket.
