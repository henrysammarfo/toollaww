TOOLLAW is Agent Infra for tools on AgentTeams: a five-role crew that compiles who may call which Skill or MCP tool, with which arguments, into a fail-closed allowlist. Policy Compiler writes a hashed artifact; Red Team must lose in the Matrix room; Gateway Auditor proves forbidden calls did not execute and emits receipts. Human ALLOW is L3-only. Skills and MCP-shaped contracts are first-class. Apache-2.0.
